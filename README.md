# 黄金 / 比特币 双向对冲阶梯加仓 EA (MT5)

MetaTrader 5 自动化交易 EA（MQL5），主要交易品种为 **黄金 XAUUSD** 与 **比特币 BTCUSD**。
双向对冲、逆势阶梯加仓、总盈利达标全平，内置图形化面板与多重风控。

**在线介绍页：** https://jliushi.github.io/mt5-gold-btc-ea/
**EA 源码：** [`GoldBTC_HedgeGrid_EA.mq5`](./GoldBTC_HedgeGrid_EA.mq5)

---

## 功能（严格对应 7 条规则）

1. **双向交易 · 全天建仓 · 点差风控** —— 多空同时持仓，全天可建仓；点差超过 `InpMaxSpreadPoints` 时禁止开仓（含加仓）。
2. **20 / 60 均线，首单免金叉** —— 加载均线用于展示与判断多空头；首单**不看金叉死叉**，自动同时开多、空首单。
3. **仅逆势阶梯加仓** —— **关闭顺势加仓**；价格逆向运行满一个网格间距即加仓，加仓**不看均线交叉**。
4. **手数与次数封顶** —— 固定首单手数、固定逆势加仓手数；`InpMaxLotPerOrder` 单次最大手数封顶，`InpMaxAddCount` 每方向最大加仓次数。
5. **只按总盈利全平** —— 无均价止盈止损、无跟踪止损；总浮盈 ≥ `InpTargetProfit` 即全部平仓，其余平仓功能全部关闭。
6. **秒进秒出熔断** —— 连续 `InpScalpMaxStreak` 轮「单轮存活 < `InpScalpSeconds` 秒」即停止 EA，防止异常行情反复触发。
7. **图形面板** —— 图表左上角实时显示状态 / 点差 / 均线 / 多空持仓 / 浮盈 / 加仓次数，并含「暂停 · 全平 · 复位」按钮。

## 参数一览

| 参数 | 默认 | 说明 |
|---|---|---|
| `InpMagic` | 20260928 | 魔术号，黄金与比特币两图表设不同值 |
| `InpTargetProfit` | 50.0 | 总盈利目标（账户货币），达标全平 |
| `InpFirstLot` | 0.01 | 首单固定手数 |
| `InpAddLot` | 0.01 | 逆势加仓固定手数 |
| `InpMaxLotPerOrder` | 1.00 | 单次最大手数（封顶） |
| `InpMaxAddCount` | 10 | 每方向最大加仓次数 |
| `InpGridStepPoints` | 300 | 逆势阶梯加仓间距（点） |
| `InpFastMA` / `InpSlowMA` | 20 / 60 | 快 / 慢均线周期 |
| `InpMaxSpreadPoints` | 50 | 最大点差（点），超限禁开 |
| `InpOpenBuyFirst` / `InpOpenSellFirst` | true | 是否自动开多 / 开空首单 |
| `InpScalpSeconds` | 15 | 单轮存活小于该秒数视为秒进秒出 |
| `InpScalpMaxStreak` | 3 | 连续 N 轮秒进秒出则停止 EA |

## 安装

> 建议使用 **对冲（Hedging）账户**，否则同图表多空会相互抵消。

1. 下载 [`GoldBTC_HedgeGrid_EA.mq5`](./GoldBTC_HedgeGrid_EA.mq5)。
2. MT5「文件 → 打开数据文件夹」，放入 `MQL5\Experts\`。
3. 在 MetaEditor 打开，按 `F7` 编译（无报错生成 .ex5）。
4. 分别在 **XAUUSD** 与 **BTCUSD** 图表拖入 EA，两图表用不同 `InpMagic`。
5. 勾选「允许算法交易」，工具栏「算法交易」按钮变绿。
6. 先在 **模拟账户 / 策略测试器** 验证后再考虑实盘。

## 面板按钮

- **暂停 / 运行** —— 暂停后不再开新仓（不影响已有持仓与全平逻辑）。
- **全平** —— 手动一键平掉本图表本 EA 的全部持仓（应急用）。
- **复位** —— 解除「秒进秒出」熔断锁定，清零连击计数。

## 策略逻辑说明

- **建仓周期**：从空仓 → 建仓记为一轮的开始；总浮盈达标全平结束该轮。
- **秒进秒出判定**：若一轮从建仓到全平的存活时间 < `InpScalpSeconds`，连击 +1；否则清零。连击达到 `InpScalpMaxStreak` 即锁定停止，需手动「复位」。
- **加仓参考价**：多单以当前最低开仓价、空单以当前最高开仓价为基准，逆向再走一个 `InpGridStepPoints` 才加下一笔，形成阶梯。
- **状态持久化**：熔断标志 / 连击数 / 建仓时间通过 `GlobalVariable` 保存，重启终端后仍保留。

## ⚠ 风险提示

本 EA 使用双向对冲 + 逆势（马丁式）阶梯加仓。逆势加仓会随行情不利放大持仓与保证金占用，
在单边趋势中可能造成快速且巨大的亏损甚至爆仓。**本项目仅供技术学习与研究，不构成任何投资建议**，
实盘盈亏与风险完全由使用者自行承担。请务必先在模拟环境充分测试，并使用可承受损失的资金。
